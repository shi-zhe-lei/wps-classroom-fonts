WPS 课件字体助手 v1.1.0 新增课件补充组，可以单独安装、检查和撤销，原有数学、英语及中文字体分组继续保留。

**下载包附带 9 个开源 STIX Two 字体文件。** 其余字体需要从自己有权使用的本地字体来源导入；完整配置共 65 个文件。

## 本次更新

- 新增 `lesson` 分组，包含等线、方正仿宋_GBK、方正黑体_GBK、方正楷体_GBK、方正兰亭黑_GBK、方正兰亭中粗黑_GBK、方正准圆_GBK 的精确版本清单。
- 支持课件补充组独立安装、检查、撤销、本地导入及桌面入口。新增 7 个完整字体文件约 74.4 MiB，未做字体裁剪。
- 完整本地配置从 58 个文件扩展到 65 个，约 176.46 MiB；原有 58 个文件及其校验值保持一致。
- **NEU-BZ-S92 尚未取得完整文件，未包含在包内。** 安装会提示待补；检查 `lesson` 或 `all` 时，如果当前账号也没有该字体，会报告缺失。
- 完善中英文操作说明，补充从旧包升级及各分组独立撤销的测试。

## 下载与使用

下载本页附件 **`wps-classroom-fonts-v1.1.0.zip`**，解压后关闭 WPS，以普通桌面用户运行：

```bash
bash install.sh
bash check.sh
```

公开包默认安装附带的 9 个开源字体。已有完整本地包时，默认安装完整配置。安装完成后重新打开 WPS 和原课件检查显示效果。

准备课件补充组时，先导入符合清单版本的本地字体，再安装：

```bash
python3 tools/import-fonts.py /path/to/your-fonts --group lesson
bash install.sh lesson
bash check.sh lesson
```

需要撤销时，明确选择分组，例如 `bash undo.sh lesson`。这只撤销本工具管理的课件补充组，保留其他分组；公开包的撤销命令为 `bash undo.sh open`。

将 ZIP 和 `.zip.sha256` 下载到同一目录后，可在 Linux 上校验：

```bash
sha256sum -c wps-classroom-fonts-v1.1.0.zip.sha256
```

## 验证与范围

本次功能更新已通过本地 29 项测试，覆盖字体安装、重复安装、旧包升级、独立撤销、公开内容检查及发布打包。公开 CI 不携带扩展字体，因此跳过其中 2 项完整包测试。实际课件显示仍需在目标麒麟 / WPS 环境中确认。

工具和文档采用 MIT，附带 STIX Two 字体采用 SIL OFL 1.1。公开附件不包含个人日志或未确认再分发许可的扩展字体。详细说明见 [项目 README](https://github.com/shi-zhe-lei/wps-classroom-fonts/tree/v1.1.0#readme)。

## English

Version 1.1.0 adds an independent `lesson` group for seven exact font versions, expanding the complete local profile from 58 to 65 files while preserving the original fonts. Installation, checking, import, and undo support this group separately. Public downloads still bundle only nine OFL-licensed STIX Two files; other fonts require authorized local sources. NEU-BZ-S92 remains unavailable and is reported as pending. Close WPS before installation and reopen your original document afterward to verify rendering.
